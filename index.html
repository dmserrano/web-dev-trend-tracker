Astro 7 alpha ships with Rust compiler + Vite 8

New release

The .astro compiler has been rewritten in Rust, Markdown/MDX processing moves to a new Rust pipeline, and Astro now sits on Vite 8. Builds are 15–61% faster depending on project size.

Source: InfoQ — Astro 7: Rust Compiler, Vite 8, Up to 61% Faster Builds

Vite 8.0 released, ships Rolldown by default

New release

Rolldown, a Rust-based bundler, now replaces both esbuild (dev) and Rollup (prod) in a single tool, claiming 10–30x speed over Rollup while keeping Rollup plugin API compatibility.
